# MyBlog

ASP.NET Core, Entity Framework Core ve PostgreSQL ile geliştirilen kişisel blog projesi.

## Proje Yapısı

- backend: API, iş mantığı, veri erişimi ve domain katmanları.
- frontend: Blog arayüzü için ayrılan bölüm.
- devops: Yerel geliştirme ortamı yapılandırmaları.

## Durum

Geliştirme aşamasındadır.
